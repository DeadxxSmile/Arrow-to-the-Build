This directory is populated by `npm run fetch:icons` during a Windows build.

The downloaded skill icons are The Elder Scrolls Online game assets retrieved from
UESP's public file archive for use by this free, non-commercial fan companion. They
remain the property of ZeniMax Media/Bethesda Softworks and are not covered by ATTB's
GPL license. ATTB keeps its letter-based fallback when an icon cannot be downloaded.
