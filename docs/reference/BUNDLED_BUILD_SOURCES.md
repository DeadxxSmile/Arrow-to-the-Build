# Mighty Seven build research

The seven bundled JSON files are ATTB-authored progression guides, not verbatim copies of another creator's page. They combine current Update 50 pure-class skill setups with ATTB's own Level 1-50 unlock order, temporary skills, prerequisite rows, CP graph, gear stages, solo/duo warnings, and disabled placeholders for future organized-group and PvP variants.

## Editorial policy

- Skill bars, Class Mastery choices, build identities, and endgame set directions are cross-checked against current build research.
- Progression order, explanatory text, starter gear, warnings, and variant policy are written specifically for ATTB.
- No third-party build prose or artwork is bundled.
- The default JSON targets a practical pure-class Solo / Duo PvE character. It is not represented as a trial-dummy parse, healer, tank, or PvP build.
- Endgame gear is presented as an endpoint menu because penetration, movement, group buffs, DLC ownership, and outside healing can change the best combination.
- The JSON remains human-editable and can be replaced or extended by future community builds and the planned Build Creator.
