# ATTB build JSON format: schema version 3

The complete authoring documentation now lives in:

- [`BUILD_JSON_GUIDE.md`](BUILD_JSON_GUIDE.md), step-by-step setup, field reference, examples, validation, images, and bundling
- [`BUILD_TEMPLATE.json`](BUILD_TEMPLATE.json), valid importable starter build
- [`BUILD_SCHEMA.json`](BUILD_SCHEMA.json), machine-readable schema
- [`SKILL_CATALOG.md`](SKILL_CATALOG.md), stable skill-line and skill IDs

ATTB v1.0 accepts schema version 3 only. Bundled and imported builds use the same format.
