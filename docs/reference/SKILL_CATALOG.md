# Bundled ESO Skill Catalog

ATTB includes a single catalog at `resources/data/eso-skill-catalog.json`.

The renderer reaches it through the `#catalog` subpath declared in `package.json`, so there is one
file rather than a main-process copy and a renderer copy that can drift apart. Regenerate it with
`python tools/generate_skill_catalog.py`, which validates morph/base links before writing.

The catalog is human-readable JSON and records:

- Category and skill-line names
- Class association when applicable
- Maximum line rank
- Ultimate, active, morph, and passive names
- Base-to-morph relationships
- Maximum purchasable ranks
- Known active/ultimate line-rank unlocks
- Currency type, including Class Mastery and tracking-only entries

Build JSON remains responsible for build-specific recommendation order, status, phase, notes, and images. This separation lets ATTB track every selected skill without forcing every build author to duplicate the complete game catalog.

## Stable ids

Build files reference catalog entries by `catalog_skill_id` (for example `herald__fatecarver`), not by
display name. Ids are `{line_id}__{slugged_skill_name}` and are generated by
`tools/generate_skill_catalog.py`, which validates every base/morph relationship before writing.

Changing an existing id is a breaking change for every build file that references it. Renaming a
skill's display text is not. Update 50 renamed several abilities, passives, and Class Mastery choices;
`tools/generate_skill_catalog.py` applies display-name overrides after ids are generated so existing
characters and community build files keep resolving to the same entries.
