What ATTB does

One local workspace for the whole ESO build journey.

Character tracking and build authoring use the same structured data, but CURRENT game state and TARGET build guidance stay deliberately separate.

01

Character-specific progression

Track the real name, level, race, alliance, attributes, skill-line ranks, purchases, gear, Champion Points, build, and variant for each character.

02

Exact unlock roadmap

Recommendations use audited Update 50 line ranks, exact passive-point gates, prerequisites, morph readiness, Skill Points, and build priority before calling a purchase available.

03

Complete skill tracking

Record class, weapon, armor, World, Guild, Alliance War, racial, crafting, Scribing, and Class Mastery progression instead of only the final bar.

04

Gear roadmaps

Leveling, starter, intermediate, and final stages can track every individual armor slot, jewelry piece, and weapon with traits, enchants, sources, and alternatives.

05

Action bars & rotations

Compare the abilities ESO currently sees with structured front and back bars, ultimates, unlock timing, rotations, and priority systems for each progression band.

06

Champion Point planning

Track earned and spent points, current slottables, required connection paths, recommended branches, optional alternatives, and final Craft, Warfare, and Fitness bars.

07

Combat companions

All eight current combat companions are included with two curated starter setups each, plus build-authored companion targets, gear traits, weapons, skills, and priority order.

08

Local ESO synchronization

The bundled single-purpose addon exports observed character state through ESO SavedVariables. New characters are discovered locally and only linked when you approve them.

09

Full visual Build Editor

Create guided builds, start from the advanced template, fork protected bundled builds, import community JSON, edit every major section, and review before saving.

10

Safe drafts & revisions

Recovery autosave, undo/redo, immutable saved revisions, protected bundled originals, readable JSON mirrors, and external-change protection keep authoring recoverable.

11

Portable Schema 4 builds

Bundled, imported, manually edited, and visually authored builds share the same human-readable JSON format with stable catalog IDs and runtime validation.

12

Four coherent themes

ATTB Default, Deep Dark, Light, and Old Scrolls share the same layout and typography while changing the palette and surface treatment through one semantic theme system.

How it works

Start with reality. Build toward the target.

ATTB is designed around the difference between what ESO says you own right now and what the build recommends next.

1

Add or discover the character

Create a profile manually, restore a backup, or let the optional ESO addon discover the character you are actually playing.

2

Choose or create the TARGET build

Use one of the Mighty Seven, attach a compatible saved build, create a guided draft, or seed a new editable build from the synchronized character state.

3

Follow the next useful step

Use the unlock roadmap, phase hotbars, gear stages, Champion Point paths, companion setup, and build-specific tips instead of jumping straight to endgame screenshots.

ATTB ESO Companion Addon 1.1.0

Let ESO report the character. Keep the build in ATTB.

The desktop app bundles one focused, data-only ESO addon. It observes the character you are playing and writes a local multi-character snapshot through ESO's normal SavedVariables system.

Single local exporter

ArrowToTheBuild

The addon captures character identity, level, attributes, available points, skill lines, purchased skills and morphs, passive ranks, action bars, equipped gear, and Champion Point state. It does not automate gameplay or communicate directly with the desktop app.

SavedVariables\ArrowToTheBuild.lua
/reloadui

ESO controls when SavedVariables reach disk.

The addon can capture changes in ESO memory, but ESO decides when the physical Lua file is written. Loading screens, logout, exit, and other save opportunities may refresh it naturally. If the desktop looks stale, /reloadui is the reliable refresh-now path.

Observed CURRENT state

Imported data stays clearly identified as game state instead of silently becoming authored build guidance.

TARGET stays desktop-owned

Sync never overwrites Build Notes, future unlocks, variants, gear roadmap, companion planning, or other authored recommendations.

Explicit discovery

New ESO characters are never silently created or merged. You choose whether to ignore, link, track, or create a new build from them.

One streamlined source

The desktop watches one SavedVariables file and the addon uses a direct, focused ESO API collection path for the data ATTB needs.

The Mighty Seven

A practical progression build for every ESO class.

ATTB includes one flexible pure-class PvE starting point per class. Each build carries setup help, exact catalog-linked unlocks, leveling bands, hotbars, gear stages, Champion Point paths, consumables, warnings, Scribing guidance, Class Mastery choices, and companion recommendations.

The bundled builds are progression-oriented starting points, not claims that one loadout is perfect for every trial, dungeon, arena, PvP campaign, or group composition.

Audited progression data

Only call it available when ESO actually allows it.

The Update 50 skill catalog tracks exact line gates for active skills and exact per-point gates for ordinary passives. Morph readiness is kept separate from the line rank required to unlock the ability family.

  • 967 player skill rows in the audited catalog
  • Every ordinary passive point has a verified unlock rank
  • Morphs require the base ability to reach Rank IV
  • Recommendations also respect prerequisites and available Skill Points
Combat companions

Plan the companion beside the character.

Choose the companion, choose a curated or build-authored setup, and use the full detail area for gear direction and actual ability priority instead of squeezing sixteen presets into selection cards.

  • All eight current combat companions
  • Two curated starter presets per companion
  • Weapon, armor weight, and trait guidance
  • Five ordered abilities, Ultimate, notes, and source guidance
Visual build authoring

Create, import, fork, revise, and save without hand-editing JSON.

The Build Editor is a full second workspace, not a settings panel. Guided creation can produce a class-specific scaffold, while advanced authors can edit the same Schema 4 data directly through purpose-built pages.

  • Guided Build and Blank Advanced Build starting points
  • Protected forks of bundled builds and community JSON import
  • Recovery autosave, undo/redo, immutable revisions, and JSON mirrors
  • Visual editing for skills, phases, gear, CP, companions, loadouts, variants, and review

Windows installation

Install the desktop app. Let it manage the optional ESO addon.

ATTB is packaged as a normal Windows installer. No separate runtime, account, database server, or Minion installation is required for normal use.

1

Download the installer

Grab ATTB-Setup-2.1.6.exe from GitHub Releases and run it. Existing ATTB desktop data is preserved when upgrading.

2

Choose addon sync or stay manual

On first run, ATTB can detect your ESO profile and install the bundled ArrowToTheBuild addon. You can skip this and use manual tracking at any time.

3

Use /reloadui when you want fresh data

ESO owns SavedVariables timing. If the desktop snapshot is stale, run /reloadui in ESO and ATTB can read the newly written local snapshot.
