What ATTB does

Everything for the build, in one place that runs offline.

Tracking your character and authoring a build share the same underlying data. What ESO says you have now and what the build wants you to aim for are kept firmly apart, so syncing never scribbles over your plan.

01

Character-specific progression

Track the real name, level, race, alliance, attributes, skill-line ranks, purchases, gear, Champion Points, build, and variant for each character.

02

Exact unlock roadmap

Recommendations use audited Update 50 line ranks, exact passive-point gates, prerequisites, morph readiness, Skill Points, and build priority before calling a purchase available. Temporary leveling skills also know when their job is done, so yesterday's filler stops shouting from the top of the list.

03

Complete skill tracking

Every skill line counts: class, weapon, armor, World, Guild, Alliance War, racial, crafting, Scribing, and Class Mastery. Not just the two bars you fight with.

04

Gear roadmaps

Leveling, starter, intermediate, and final stages can track every individual armor slot, jewelry piece, and weapon with traits, enchants, sources, and alternatives.

05

Action bars & rotations

Put what you're actually slotting next to what the build wants: front and back bars, ultimates, when each skill comes online, and a rotation to run for every stage of leveling.

06

Champion Point planning

Track earned and spent points, current slottables, required connection paths, recommended branches, optional alternatives, and final Craft, Warfare, and Fitness bars.

07

Combat companions

All eight current combat companions are included with two curated starter setups each, plus build-authored companion targets, gear traits, weapons, skills, and priority order.

08

Local ESO synchronization

The bundled single-purpose addon exports observed character state through ESO SavedVariables. New characters are discovered locally and only linked when you approve them.

09

Full visual Build Editor

Create guided builds, start from the advanced template, fork protected bundled builds, import community JSON, edit every major section, and review before saving.

10

Safe drafts & revisions

Recovery autosave, undo/redo, immutable saved revisions, protected bundled originals, readable JSON mirrors, and external-change protection keep authoring recoverable.

11

Portable Schema 4 builds

Bundled, imported, manually edited, and visually authored builds share the same human-readable JSON format with stable catalog IDs and runtime validation.

12

Six coherent themes

ATTB Default, Deep Dark, Light, Old Scrolls, SkyTrim, and Woodland share the same layout and typography while changing the palette and surface treatment through one semantic theme system.

13

Help & Tools workspace

Help & Tools is now its own workspace, with Gear, Combat, Progression, Companions, and Reference sections instead of one giant drawer. Traits, sets, glyphs, stats, buffs, Mundus Stones, Champion Points, Scribing, build jargon, and more stay close to the plan and answer the question “why does this matter to my build?”

How it works

Three steps, then go play.

The whole thing hangs on one idea: what you own right now and what the build wants next are two different lists, and ATTB always knows which is which.

1

Add or discover the character

Create a profile manually, restore a backup, or let the optional ESO addon discover the character you are actually playing.

2

Pick the build you're chasing

Grab one of the Mighty Seven, attach a saved build, spin up a guided draft, or build a fresh one straight from the character you just synced.

3

Do the next thing it tells you

Unlock roadmap, hotbars for the stage you're at, gear stages, Champion Point paths, companion setup. The next useful move, not a level-50 screenshot you can't use yet.

ATTB ESO Addon 1.1.1

The addon reads your character. That's all it does.

The desktop app ships with one small addon that does exactly one job: it watches the character you're playing and writes a snapshot to a local file through ESO's normal SavedVariables system. No accounts, no network, no reaching back into the game.

Single local exporter

ArrowToTheBuild

It grabs identity, level, attributes, spare points, skill lines, purchased skills and morphs, passive ranks, both action bars, equipped gear, and Champion Points. It doesn't press buttons for you and it doesn't talk to the desktop app. It writes a file; that's the whole relationship.

SavedVariables\ArrowToTheBuild.lua
/reloadui

ESO controls when SavedVariables reach disk.

The addon can capture changes in ESO memory, but ESO decides when the physical Lua file is written. Loading screens, logout, exit, and other save opportunities may refresh it naturally. If the desktop looks stale, /reloadui is the reliable refresh-now path.

Synced data is just game state

What comes in from ESO stays labeled as what you actually own. It never quietly turns itself into build advice.

Your plan is yours

Syncing won't touch your Build Notes, future unlocks, variants, gear roadmap, or companion planning. That side of the wall is off limits.

Nothing happens without a yes

A newly spotted character isn't added or merged on its own. You decide: ignore it, link it, track it, or build from it.

One file, one job

The desktop app watches a single SavedVariables file, and the addon only collects the handful of things ATTB needs. Nothing more.

The Mighty Seven

One solid build per class, ready to level.

Every class gets a flexible, pure-class PvE build to start from. Each one comes fully loaded: setup help, catalog-linked unlocks, leveling bands, hotbars, gear stages, Champion Point paths, consumables, warnings, Scribing guidance, Class Mastery picks, and companion recommendations. Temporary leveling purchases now come with real handoff points too, so the build knows when it is time to stop asking for the skill that got you there.

They're starting points that carry you from early levels to a working endgame setup. They're not a promise that one loadout wins every trial, arena, and PvP campaign. Nothing does.

Audited progression data

It won't tell you to buy something you can't buy yet.

The Update 50 catalog knows the exact rank each active skill unlocks at and the exact point each passive opens up. It also knows a morph isn't the same as the rank that unlocks the skill, so it won't confuse the two and send you shopping early. And when a leveling skill has finally done its job, ATTB can retire it from the roadmap instead of nagging you to buy it forever. You keep the final say: mark one done early when you know you're finished with it, or keep one past its cutoff if it's still pulling weight.

  • 967 player skill rows in the audited catalog
  • Every ordinary passive point has a verified unlock rank
  • Morphs require the base ability to reach Rank IV
  • Recommendations also respect prerequisites and available Skill Points
  • Temporary unlocks can retire by level, skill-line rank, or a replacement unlock
  • Owned retired skills show reclaimable Skill Points without rewriting the ESO snapshot

Windows installation

Download it, run it, done.

ATTB is a normal Windows installer. No runtime to install first, no account to make, no database to set up, no Minion. Just the app.

1

Download the installer

Grab ATTB-Setup-2.2.0.exe from GitHub Releases and run it. Existing ATTB desktop data is preserved when upgrading.

2

Choose addon sync or stay manual

On first run, ATTB can detect your ESO profile and install the bundled ArrowToTheBuild addon. You can skip this and use manual tracking at any time.

3

Use /reloadui when you want fresh data

ESO owns SavedVariables timing. If the desktop snapshot is stale, run /reloadui in ESO and ATTB can read the newly written local snapshot.
