Why ATTB

Progression guidance instead of another static bar screenshot.

ATTB keeps recommendations transparent, editable, and tied to the ranks and purchases recorded for each character.

Character-specific progression

Track real level, race, alliance, attributes, CP totals, skill-line ranks, and every selected ability or passive.

Next-step recommendations

Catalog IDs, prerequisites, morph requirements, passive ranks, and build priorities determine what is actually available next.

Piece-by-piece equipment

Leveling, starter, intermediate, and final stages include individual armor, jewelry, and weapon slots plus acquisition details.

ESO-inspired hotbars

Each progression phase shows front bar, back bar, ultimate slots, and the rotation or priority system beneath them.

The Mighty Seven

One bundled pure-class Solo / Duo PvE progression build for every ESO class, ready on first launch.

Offline-first and human-readable

Characters live in local SQLite. Builds and backups remain ordinary JSON that can be inspected and shared.

The Mighty Seven

Start with any class.

The launch bundle includes Arcanist, Dragonknight, Necromancer, Nightblade, Sorcerer, Templar, and Warden progression builds. Each is a practical Solo / Duo baseline with structured phases, gear stages, CP paths, consumables, warnings, and final-build goals.

Build for Windows

One batch file. Tests first. Installer second.

Download or clone the repository, install the current Node.js LTS release, and run BUILD-ATTB.bat. It installs locked dependencies, runs the full suite, builds the renderer, and creates the NSIS installer without launching it.

  1. Download or clone the ATTB repository.
  2. Open the folder and run BUILD-ATTB.bat.
  3. Find the installer under dist\ATTB-Setup-<version>.exe.

The installer is unsigned. Windows may show Unknown Publisher or SmartScreen warnings. Review the source and only bypass warnings for files you trust.
